# ⏰ 時鐘 Clock App

**版本：1.2.0**

macOS 風格的 Windows 桌面時鐘。程式常駐在系統匣，按 **Ctrl+Alt+C** 就會跳出來，再按一次就隱藏。

---

## 功能

| 頁籤 | 說明 |
|------|------|
| 世界時鐘 | 預設有鹽湖城、台北、紐約、德州。按「+ 新增時區」可以從**世界各國首都**和**中國的直轄市、省會、自治區首府、香港、澳門**裡挑選（依地區分組，可以用中文、英文或國家名稱搜尋，雙擊或按 Enter 直接新增）。每個城市右邊的 ✕ 可以把它移除，預設的城市和本地時區（台北）也都能移除 |
| 鬧鐘 | 新增鬧鐘（用 ▲▼ 調整時、分，按住可以連續調整，也可以用鍵盤上下鍵或滑鼠滾輪）、設定標籤、選擇鈴聲（四季—春／經典響鈴）、勾選**提前 10 分鐘先響一次**（時間到之前 10 分鐘先響一次預告，並念出「還有 10 分鐘，＋標籤」，時間到再正式響）、開關鬧鐘、按 ✎（或直接點鬧鐘）**修改**、按 ✕ 刪除。可以選**單次**（選日期）或**每週**（自選週一到週日，或一鍵選每天／平日／週末，並設定開始和結束日期），也可以勾選儲存後加入 Google 日曆。時間到會跳出視窗、播放鈴聲，並用語音念出鬧鐘標籤 |
| 碼錶 | 開始、暫停、繼續。執行中按左鍵 **計圈**，記下每一圈的本圈時間和累計時間（最快一圈綠色、最慢一圈紅色）；暫停後左鍵變成 **重設**，歸零並清除計圈紀錄 |
| 計時器 | 設定時、分、秒（初始都是 0），上方顯示會即時跟著變；時間到了會播放音樂並跳出提醒 |

### App 行為

- **Ctrl+Alt+C**：叫出或隱藏視窗。視窗會出現在滑鼠所在螢幕的正中央。
- 點視窗以外的地方，或點左上角的紅點、黃點，視窗會隱藏，但程式繼續在背景跑。
- 隱藏時碼錶和計時器照樣計時，不會暫停。
- 計時結束時，視窗會自己跳出來。
- 鬧鐘時間到：視窗跳出，「鈴聲 → 念出標籤」反覆播放，按 **停止** 結束；沒按的話 1 分鐘後自動停止。
- 新增的鬧鐘和世界時鐘城市會自動儲存，App 重開或電腦重開機都還在。
- 拖曳視窗頂部的標題列可以移動位置。
- 版號顯示在視窗右上角，系統匣圖示的提示和右鍵選單也看得到。
- 系統匣圖示：
  - **左鍵**：叫出或隱藏視窗
  - **右鍵**：顯示時鐘、開機自動啟動（打勾開啟）、結束

> **為什麼不能用 Fn+C？** Fn 鍵是筆電鍵盤韌體自己處理的，Windows 收不到 Fn 的訊號，所以任何程式都沒辦法綁定 Fn 組合鍵。

## 安裝與執行

### 方式一：使用打包好的版本（推薦）

1. 到 [GitHub Releases](https://github.com/jamesldswang/Clock/releases/latest) 下載 `Clock-1.2.0-win-x64.zip`（或從別台電腦複製過來），按右鍵選「解壓縮全部」，放到固定的位置（例如 `C:\Tools\Clock`）。
2. 打開資料夾，雙擊 **`時鐘.exe`**。執行後畫面上不會跳出視窗，請看右下角系統匣有沒有出現時鐘圖示。
3. 按 **Ctrl+Alt+C** 叫出時鐘。
4. 建議在系統匣圖示按右鍵，勾選 **開機自動啟動**。

> 系統需求：Windows 10／11 64 位元。不需要安裝 Node.js。
>
> 資料夾裡的檔案都要一起保留，不能只複製 `時鐘.exe` 一個檔案。
>
> 打勾開機自動啟動之後，請不要再移動資料夾的位置，否則開機時會找不到程式。移動後重新勾選一次就好。
>
> 如果 Windows 跳出「Windows 已保護您的電腦」，點「其他資訊」再點「仍要執行」。

### 方式二：從原始碼執行

需要先安裝 [Node.js](https://nodejs.org/)（18 以上）。

```bash
cd ClockApp
npm install
npm start
```

也可以雙擊 `start.vbs`，這樣不會跳出命令列視窗。如果資料夾不在 `C:\Users\user\ClockApp`，要先用記事本打開 `start.vbs`，把裡面的路徑改成實際位置。

## 打包

```bash
cd ClockApp
npm install
npm run dist
```

打包完成後會產生：

- `dist\Clock-1.2.0-win-x64\`：可以直接執行的資料夾
- `dist\Clock-1.2.0-win-x64.zip`：同一個資料夾的壓縮檔，方便帶到其他電腦

### 發布到 GitHub Release

先在 README 的「版本紀錄」加上新版本的段落，並把 `package.json` 的版號改好，執行 `npm run dist` 之後再執行：

```bash
bash tools/release.sh
```

會建立 `v<版號>` 的 Release，說明文字取自 README 版本紀錄裡該版本的段落，並上傳 zip。GitHub 登入資料沿用 git 已存的帳密。

> **為什麼不打包成單一個 .exe？** Windows 11 的「智慧型應用程式控制」會擋下沒有數位簽章、內容又不是 Windows 認得的程式。單一 `.exe` 的打包工具會改動 Electron 主程式，所以會被擋。`build.js` 直接沿用原版 Electron 主程式，只改檔名、內容不變，所以可以正常執行。

## 鬧鐘重複方式

| 方式 | 什麼時候響 | 響完之後 |
|------|-----------|---------|
| 單次 | 只在選定的那一天、那個時間響（預設今天；07:00 已經過了就預設明天） | 自動關閉，要再用就把開關打開 |
| 每週 | 在開始到結束日期之間，選到的星期幾都響。可以勾「不設結束日期」一直響下去 | 保持開啟；結束日期前最後一次響完會自動關閉 |

舊版建立的「指定日期」鬧鐘現在顯示成單次；舊版的每週鬧鐘沒有期間，照常每週響。

### 加到 Google 日曆

- 新增鬧鐘時，「儲存後加入 Google 日曆」預設是打勾的，不想加就取消勾選。按儲存後，瀏覽器會打開 Google 日曆的新增活動頁，標題（⏰ + 鬧鐘標籤）、日期和時間都已經填好，按 **儲存** 就加進日曆了。
- 每週鬧鐘會建立**每週重複**的活動，重複的星期跟鬧鐘選的一樣，從下一次會響的那天開始；有結束日期的話，日曆上的重複也會在那天結束。
- 當時沒加的話，之後可以點鬧鐘卡片上的 **📅 加到 Google 日曆**。
- 瀏覽器要先登入你的 Google 帳號。

## 已知限制

- **念標籤需要中文語音**：Windows 要有中文語音（設定 → 時間與語言 → 語音）才念得出中文標籤；沒有的話只會響鈴聲，或用英文語音念。
- **Google 日曆是單向、一次性的**：只會在建立鬧鐘時幫你打開新增活動的頁面。之後在 App 裡修改、刪除或關閉鬧鐘，日曆上的活動不會跟著變（修改鬧鐘時，可以勾「儲存後加入 Google 日曆」另外建一個新活動），要自己去日曆刪。
- **資料不會跟著 zip 走**：鬧鐘和城市存在這台電腦上（`%APPDATA%\時鐘`），把 zip 帶到另一台電腦是全新的，不會有原本的鬧鐘。
- **程式要在執行中，快捷鍵才有作用**：按 Ctrl+Alt+C 沒反應時，先看系統匣有沒有時鐘圖示。沒有的話代表程式沒在跑（例如重開機後沒設定開機自動啟動），雙擊 `時鐘.exe` 重新打開就好。
- **快捷鍵可能被佔用**：如果 Ctrl+Alt+C 已經被其他程式用掉，快捷鍵會沒有作用。這時可以改用系統匣圖示叫出視窗，或在 `main.js` 換一組快捷鍵。

## 版本紀錄

### 1.3.0（2026-11-22）

- 重複方式改成「單次」和「每週」兩種：單次要選日期（取代原本的「指定日期」）
- 每週鬧鐘可以設定開始和結束日期，也可以不設結束日期
- 每週鬧鐘也可以加入 Google 日曆，會建立每週重複的活動（有結束日期就到那天為止）

### 1.2.0（2026-11-05）

- 鬧鐘新增「提前 10 分鐘先響一次」選項：時間到之前 10 分鐘先響一次預告（念出「還有 10 分鐘，＋標籤」），時間到再正式響；新增或修改鬧鐘時都可以勾選

### 1.1.0（2026-11-05）

- 世界時鐘可以選世界各國首都，以及中國的直轄市、省會、自治區首府和香港、澳門，共 233 個城市；新增視窗加上搜尋框，依地區分組
- 同一個時區可以加入多個城市（例如北京和成都）
- 世界時鐘的城市可以移除（按城市右邊的 ✕），包括預設的城市和本地時區
- 已經設好的鬧鐘可以修改：按 ✎ 或直接點鬧鐘，可以改時間、重複方式、日期、標籤和鈴聲；修改後鬧鐘會自動重新開啟

### 1.0.1（2026-11-04）

- 修正系統匣圖示在 Windows 上只顯示灰色框框的問題（視窗圖示也一起修正）
- 系統匣圖示附上高解析度版本，在 150%／200% 縮放的螢幕上不會模糊

### 1.0.0（2026-11-04）

- 第一個正式版本
- 把 `clock.html` 包成 Electron 桌面 App，常駐系統匣
- 加入全域快捷鍵 Ctrl+Alt+C，按一次叫出、再按一次隱藏
- 點視窗外面會自動隱藏，隱藏時碼錶和計時器繼續運作
- 計時結束時自動跳出視窗
- 系統匣選單可以設定開機自動啟動
- 計時器初始值改成 0，調整時、分、秒時上方顯示即時連動，超過 1 小時顯示成 `時:分:秒`
- 世界時鐘加入德州（美國中部時間）
- 新增鬧鐘的時間改用 ▲▼ 轉輪調整（支援按住連續調整、鍵盤上下鍵、滑鼠滾輪）
- 視窗右上角與系統匣顯示版號
- 鬧鐘時間到會響鈴，並用中文語音念出鬧鐘標籤（反覆播放，按「停止」或 1 分鐘後結束）

- 鬧鐘可以刪除（卡片右邊的 ✕）
- 鬧鐘重複方式：單次（響完自動關閉）、每週（自選星期幾，可快速選每天／平日／週末）、指定日期（年／月／日用 ▲▼ 調整，響完自動關閉）

- 鬧鐘與世界時鐘城市會自動儲存，重開 App 或重開機都不會消失
- 指定日期的鬧鐘可以一鍵加入 Google 日曆
- 碼錶新增「重設」（暫停後按左鍵）；計圈紀錄改成顯示本圈時間與累計時間，並標出最快、最慢的一圈
- 提供可攜式打包版（zip），解壓後雙擊 `時鐘.exe` 就能執行
